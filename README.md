A simple ELF binary parser.

Setup:
```
g++ -Wall -Wextra -std=c++17 main.cpp ELFPrint.cpp ELFParse.cpp -o elfinspect
```

Usage:
```
./elfinspect <path_to_elf/filename>
```

Example:
```
./elfinspect /bin/ls
```
